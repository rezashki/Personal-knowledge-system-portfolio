# Personal Knowledge System for Learning and Application

> A privacy-safe portfolio overview of an Obsidian-based system for turning raw information into reusable knowledge and practical work.

## Why I built it

Important information often remains scattered across notes, documents, meetings, and AI conversations. This system creates a repeatable path from an unstructured input to a decision, a learning outcome, or a project action.

## The operating loop

```text
Capture -> Define a learning goal -> Preserve the source -> Build understanding
        -> Link related knowledge -> Apply in a real project -> Review and improve
```

## How the system is organized

| Area | Purpose |
| --- | --- |
| Inbox | Capture ideas, questions, raw notes, and source material without premature classification. |
| Sources | Keep original evidence separate from derived knowledge. |
| Knowledge Base | Turn sources into connected, reusable concepts written in my own words. |
| Learning Paths | Define a target skill, prerequisites, practice, and evidence of progress. |
| Projects | Connect knowledge to active work, decisions, and next actions. |
| Decisions | Record important choices with their rationale, risks, and review point. |
| Prompts and AI Workflows | Maintain reusable AI instructions and quality checks. |

## Design principles

- **Learning, not passive storage:** every important note should support understanding, practice, or a real decision.
- **Traceability:** sources, facts, assumptions, decisions, and actions remain distinguishable.
- **Reuse through links:** related concepts and projects are connected so knowledge can be found when needed.
- **Privacy by design:** confidential project data stays in private workspaces; this repository contains only a sanitized overview.

## Example use case

When a new article, meeting note, or AI conversation arrives, I capture it first. I then preserve the source, extract the reusable insight, connect it to an active learning path or project, and define the next action. During review, I update the outcome based on what happened in practice.
